# Project 1 - CCM College Recruitment Improvement Study

How can CCM encourage more students to take computing classes?

This project uses the Fall 2024 Non Majors Survey to learn about students taking computing classes at CCM. I looked at why students take these classes, which computing topics interest them, and where they get information about courses. These results could help CCM decide how to promote its computing classes.

## Data Science Questions

1. Where do students most often get information about computing courses at CCM?
2. Which computing topics are students most interested in?
3. What are the most common reasons students take computing classes?

## Project Files

1. **Non-Majors Survey Results - Fall 2024.csv** contains the original survey data before cleaning.
2. **non_majors_2024_cleaned.csv** contains the cleaned data saved in Part 2 and used for the analysis in Part 3.
3. **Gilby_Project1_Part2.ipynb** is the notebook where I explored the data, checked for missing values and duplicates, selected columns, and saved the cleaned CSV.
4. **Gilby_Project1_Part3.ipynb** is the notebook where I analyzed the cleaned data to answer the questions above. It includes bar charts and explanations of the results.
